# Городская мастерская с характером

Аудитория — человек с неисправным устройством в Казани. Первое действие — описать проблему и связаться с мастером.

Палитра: Workshop Blue `#0D6E8D`, Duck Yellow `#F3B51B`, Tool Ink `#11181C`, Workshop Paper `#F7F7F2`, Steel `#DCE3E6`, Ready Green `#1F8F5F`. Жёлтые кнопки всегда с тёмным текстом. Зелёный статус используется для подтверждения копирования.

Типографика: короткие крупные заголовки Unbounded; интерфейс Manrope; цены, часы и технические подписи IBM Plex Mono. Локальные подмножества кириллицы и латиницы, font-display:swap и системные fallback.

Сетка: максимум 1280 px. На десктопе первый экран состоит из крупного трёхстрочного оффера слева и мастерской с официальным маскотом справа. На мобильном — одна колонка, действия до большой иллюстрации. Карточки услуг, линейный процесс, сравнение, отзывы и контактный блок имеют разные композиции.

Фирменный элемент — оригинальная утка с телефонами и инструментом. Она сохранена без перерисовки. Жёлтая наклейка «Разберёмся» связывает маскот с живым голосом мастерской. Повтор в шапке маленький, для узнаваемости. Абстрактные устройства нарисованы кодом; фотографии посетителей не используются.

Интерактив: устройство → бренд/модель → симптом → возможная услуга → готовый текст. Результат не выдаётся за диагностику мастера. Постоянной анимации нет; необязательный оборот пропеллера не добавлен, чтобы не разбирать и не искажать официальный растровый логотип. Reduced motion отключает переходы и плавную прокрутку.

Первый визуальный проход: увеличены мелкие подписи, кнопки и текст интерфейса; выровнен перенос мобильного заголовка; шапка получила официальный маскот вместо вспомогательной пиктограммы; удалён лишний крест поверх жёлтой наклейки. Для цены заднего стекла оставлен честный запрос, поскольку прайс подтверждает заднюю крышку, а равенство этих работ не установлено.
