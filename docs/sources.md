## Не подтверждено источниками

- Срок и условия гарантии, бесплатная диагностика, универсальный срок ремонта.
- Имя/состав команды как утверждённая редакция страницы; имя мастера Фаннура встречается в отзывах, но биография, опыт и специализации отсутствуют.
- Возврат снятых деталей как правило, ремонт при клиенте, неизменность данных на устройстве.
- Детальные условия записи, бронирования, наличие каждого аксессуара.
- ИНН/ОГРНИП, email, публичный домен нового сайта, идентификатор Метрики для нового сайта.
- Условия хранения заявок и политика владельца. Статическая форма, которая лишь составляет текст для мессенджера, не должна изображать передачу заявки на сервер.
- Фотографии входа и реальных ремонтов. Ориентир «Хлебозавод № 3» дан пользователем; в просмотренных источниках отдельно не подтверждён.

## Доступность источников

Веб-парсер успешно прочитал официальный сайт и 2ГИС. Для Telegram и Яндекс Карт веб-парсер возвращал ошибки редиректа/безопасности URL, но обычный публичный HTTP GET через PowerShell успешно получил их страницы. Аутентификация, закрытые API и данные учётных записей не использовались.
