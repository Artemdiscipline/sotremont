# Проверка сайта СотРемонт

5 сентября 2026. Chromium / Playwright CLI на Windows. Проверены исходная версия Vite и production-сборка. Десктопный сервер оставлен на http://127.0.0.1:5173/.

## Результаты

- `npm run build`: успешно, включая strict TypeScript. Production JavaScript — 75,08 КБ gzip, CSS — 10,20 КБ gzip; один клиентский JS-файл. Runtime-зависимости: React и React DOM.
- 1440×1000, 768×1024, 390×844: document.scrollWidth равен ширине viewport; выходящих за границы элементов основного контента и сломанных изображений нет. Локальные шрифты загрузились.
- Пройден 21 функциональный сценарий: меню, Escape, устройство/модель/симптом, результат, корректный текст и URL WhatsApp, настоящее копирование Clipboard, переход Telegram, отказ Clipboard и ручной fallback, выбор заднего стекла и общей диагностики, очистка скрытых подробностей, смена категории, диалог политики, slider с клавиатуры, внутренние якоря, телефонные ссылки, 6 запросов аксессуаров, reduced motion.
- В Telegram проверена именно кнопка «Скопировать заявку и открыть Telegram». Текст сначала копируется, затем открывается адрес сервиса. Ответ внешней страницы подменён в тесте: сообщения никому не отправлялись. Ручной сценарий проверен при принудительном отказе Clipboard API. В Clipboard Windows переводы строк CRLF нормализуются при сравнении с textarea LF.
- Skip-link — первый элемент Tab-порядка; видимая рамка focus присутствует. Escape закрывает меню и нативный dialog. Range управляется стрелками клавиатуры. Radio, select, textarea и submit — нативные элементы.
- На мобильных есть нижняя панель с safe-area padding. В конце страницы предусмотрен запас под панель; весь контент доступен при прокрутке.
- Предпочтение reduced motion отключает плавную прокрутку и переходы. Постоянной анимации нет.
- В production — 0 ошибок JavaScript, 0 предупреждений консоли, 0 неудачных запросов. Все загружаемые ресурсы имеют origin самого сайта.
- Проверены title, description, Open Graph, JSON-LD LocalBusiness, телефон и адрес. Structured data не содержит неподтверждённого рейтинга. robots.txt и XML sitemap отдаются корректно. При `canonicalUrl:null` нет вымышленного canonical; индексация закрыта до установки реального домена.
- Основной текст: Tool Ink / Workshop Paper; вторичный текст — тёмный серый; ссылки — Workshop Blue; CTA — Tool Ink / Duck Yellow. Подтверждение копирования использует тёмный зелёный текст. Жёлтый не используется как цвет мелкого текста на светлом фоне.

## Исправлено при проверке

1. Увеличены подписи и элементы интерфейса, исправлен перенос заголовка на мобильном, зоны кнопок выбора услуг увеличены до 44 px.
2. Официальный маскот добавлен и в компактный логотип шапки; удалён лишний декоративный крест над наклейкой.
3. «Замена заднего стекла» теперь сохраняет услугу в результате и заявке. Общая диагностика больше не подставляет симптом «Попала вода».
4. Подробности «Другой проблемы» не попадают в заявку после смены симптома.
5. Telegram не оставляет пользователя без текста при отказе копирования. Вкладка закрывается, поле выделяется, появляется отдельная ссылка. Clipboard вызывается до открытия вкладки, пока документ в фокусе.
6. Даты/оценки и видимые бренды вынесены в общую конфигурацию. Добавлены fallback профиля мастера и отсутствующего рейтинга.
7. Убрана цена заднего стекла: публичный прайс подтверждает другую формулировку работы. Удалён неиспользуемый preload шрифта, вызывавший предупреждение.

## Границы проверки

Проверка размеров выполнена в Chromium, а не на физических iPhone/Android. Отправка сообщений, телефонный звонок и реальное бронирование не выполнялись. Возможность внешних площадок открыть приложения зависит от устройства пользователя. Реальные фотографии, условия гарантии и конечный домен должен предоставить владелец; конкретный список — в README и комментариях `site.ts`.
